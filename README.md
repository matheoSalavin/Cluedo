# Cluedo

Projet de jeu Cluedo réalisé dans le cadre de ma première année de BTS SIO.

## Description

Le but du jeu est de trouver le coupable, l'arme utilisée et la pièce où le crime a été commis.

Le joueur choisit un personnage, se déplace dans les pièces et fait des hypothèses pour résoudre l'enquête.

## Technologies utilisées

- PHP
- HTML / CSS
- SQLite
